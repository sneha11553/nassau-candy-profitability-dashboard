# Nassau Candy Distributor – Profitability & Margin Performance Dashboard

An interactive Streamlit dashboard for analyzing the sales and profitability performance of Nassau Candy Distributor's product lines.

## Project Overview

This project uses data analysis and visualization to understand product-level profitability, sales performance, costs, margins, and other business metrics. The dashboard provides interactive charts, key performance indicators, filters, and business insights.

## Features

- Interactive Streamlit dashboard
- Product and category performance analysis
- Sales and gross profit analysis
- Profit margin analysis
- Cost and unit analysis
- Regional and business performance insights
- Interactive Plotly visualizations
- Dashboard filters for exploring the dataset
- Key business insights and performance indicators

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Installation

1. Clone the repository:

```bash
git clone https://github.com/sneha11553/nassau-candy-profitability-dashboard.git
cd nassau-candy-profitability-dashboard
```

2. Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Dashboard

Start the Streamlit application with:

```bash
streamlit run app.py
```

The dashboard will open in your browser.

## Dataset

The dashboard uses `cleaned_data.csv` as the processed dataset for analysis and visualization.

## Deployment

The application can be deployed using Streamlit Community Cloud by connecting the GitHub repository and selecting `app.py` as the main application file.
